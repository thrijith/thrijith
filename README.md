#### How I use AI

Claude Code is part of my daily work. I direct it, and I review everything it produces.

- **Plan first:** Claude reads the code and docs, then proposes a plan. It writes nothing until I approve.
- **Written rules:** my `CLAUDE.md` asks for small diffs, the existing code style, no speculative code, and a dead-code check on every change.
- **Hooks as guardrails:** hooks block risky shell commands and start a cleanup review after larger edits.
- **One session per project:** I run Claude sessions side by side, so each project keeps its own context.
- **Verified security reviews:** I run multi-agent audits on my own repos. Separate agents check each finding before I fix it.
- **Custom MCP tools:** I built [wp-snapshot-tools](https://github.com/thrijith/wp-snapshot-tools), a Local WP addon that lets Claude Code and other MCP clients import, create, pull and push WordPress database snapshots.
